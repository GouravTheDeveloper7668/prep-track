# Build a Complete Personal Study Progress Tracker Web App

Act as a senior frontend developer, UI/UX designer, and JavaScript architect. Build a complete, polished, responsive web application called **"PrepTrack — My 120-Day Interview Journey"**.

The application is for my personal preparation for a Laravel Developer job in Noida or Gurgaon within the next 90–120 days.

Do not create just a UI mockup. All buttons, forms, charts, calendar interactions, checklists, data persistence, and JSON import/export features must work.

## 1. Technology Stack and Project Structure

Use only:

- HTML5
- CSS3 with a well-organized Core CSS design system
- Vanilla JavaScript (ES6+)
- Browser localStorage for persistent application data
- Chart.js for charts
- Font Awesome 6 icons
- Google Fonts: a cursive font such as Caveat for selected headings and accents, paired with Inter or Poppins for readable body text

Use CDN libraries where appropriate. The app should work locally without a backend or database.

Create exactly these two application pages:

- `login.php`
- `index.php`

Additional optional assets:
- `assets/css/style.css`
- `assets/js/app.js`
- `assets/js/login.js`
- `assets/js/storage.js`
- `assets/js/calendar.js`
- `assets/js/charts.js`

If practical, deliver all project files and explain how to run them locally.

Example demo credentials:
